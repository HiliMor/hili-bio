# קשב — אטלס תשומת הלב הישראלית

אבטיפוס מחקרי שבוחן כיצד תשומת הלב באתרי חדשות בישראל נעה בין נושאים ואירועים.

[תכנית העבודה המלאה](./PROJECT_PLAN.md)

## מה קיים כרגע

- wireframe אינטראקטיבי למסך “עכשיו בישראל”.
- מעבר בין חלונות זמן ומקורות.
- בחירת נושא ופתיחת כרטיס פירוט.
- המחשה של “הנושא שנעלם”.
- מחקר היתכנות ראשוני למקורות חדשות.
- probe טכני שאפשר להריץ מחדש מול המקורות.
- collector ששומר snapshots ב־SQLite בלי גוף כתבות.
- שכבת סטטוס שמחברת בין מנוע האיסוף ל־wireframe בלי להציג נתוני הדגמה כאמיתיים.

כל הנתונים שמופיעים בממשק הם נתוני הדגמה ואינם מתיימרים לתאר את סדר היום האמיתי.

## הפעלה

```bash
npm install
npm run dev
```

בדיקת המקורות:

```bash
npm run probe:sources
```

איסוף snapshot יחיד וסיכום בסיס הנתונים:

```bash
npm run collect
npm run db:summary
```

הרצת collector מקומי מדי 15 דקות:

```bash
npm run collect:watch
```

לשינוי המרווח בסביבת פיתוח:

```bash
ATLAS_INTERVAL_MINUTES=5 npm run collect:watch
```

ה־collector המקומי מתאים למחקר ולפיתוח. בפריסה אמיתית עדיף להפעיל `npm run collect` באמצעות scheduler חיצוני, כדי שלא יהיו ריצות כפולות וכדי לקבל ניטור וניסיונות חוזרים.

## מבנה

```text
index.html                  wireframe
src/main.js                 נתוני הדגמה ואינטראקציות
src/styles.css              השפה החזותית והפריסה
research/feasibility.md     מחקר היתכנות קצר
scripts/probe-sources.mjs   בדיקת זמינות ומבנה מקורות
scripts/collect.mjs         איסוף חד־פעמי
scripts/collect-watch.mjs   איסוף מחזורי לפיתוח מקומי
scripts/db-summary.mjs      סיכום מצב המאגר
data/                       בסיס הנתונים המקומי, לא נשמר ב־Git
```

## מודל הנתונים

- `collection_runs` — ריצת collector מלאה.
- `snapshots` — מצב של feed מסוים בזמן נתון, כולל כשלי רשת.
- `articles` — מטא־דאטה ייחודי של פריט; אין עמודת גוף או תקציר.
- `snapshot_items` — הקשר בין snapshot לפריטים והסדר שבו הופיעו.

## עיקרון מחקרי

המערכת מודדת תשומת לב תקשורתית לפי פרסומים ומטא־דאטה. היא אינה מודדת דעת קהל, חשיבות אובייקטיבית, אמת או הטיה פוליטית.
